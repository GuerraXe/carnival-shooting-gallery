# licenses/

This folder holds license evidence for every asset in [`../ASSET_MANIFEST.md`](../ASSET_MANIFEST.md). The procedure is in Asset Guide §3.2.

- **`<ASSET_ID>.md`, one per acquired asset.** Each file contains:
  - the source URL
  - the retrieval date
  - the creator as credited
  - the license name, version, and URL
  - the **verbatim** license statement copied from the source page
  - an archived snapshot URL, if one could be made
  - for own photography: photographer, date, camera, and a rights statement
- **Full license texts.** Download each from the official source (creativecommons.org, or the font's own `OFL.txt`) when the first asset under that license is added. Never write them from memory.

Contents: one evidence file per acquired sound (`SFX_*.md`, `AMB_MIDWAY.md`, generated by `asset-src/work/audio/evidence.pl`) and the CC0 1.0 legal code (`CC0-1.0.txt`, downloaded from creativecommons.org on 2026-11-11); one file per image sprite (`BG_*`, `FG_*`, `TGT_*`, `DEC_*`, `UI_*`, `OV_*`), all the project's own art generated by `tools/sprite_bake.cpp` (D-044). No font is bundled.
